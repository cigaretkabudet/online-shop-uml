## Описание

### Назначение работы
Моделирование процесса онлайн-покупки средствами UML.

### Диаграмма последовательности
Моделируется сценарий «Оформление заказа и оплата». Участники:
Покупатель, Корзина, Склад, Система оплаты, Служба доставки.
Порядок сообщений: проверка наличия → резервирование → оплата →
подтверждение → создание доставки. Блоки `alt` отражают две ветки:
наличие/отсутствие товара и успех/отказ оплаты. При отказе оплаты
выполняется снятие резерва (компенсирующее действие).

### Диаграмма состояний
Объект «Заказ» проходит состояния: Создан → ОжидаетОплаты → Оплачен →
Собирается → Отправлен → Доставлен. Состояние «Отменён» достижимо
из «ОжидаетОплаты» (тайм-аут/отказ), «Оплачен» (возврат средств)
и «Собирается» (повреждение/нет на складе). Это отражает типовые
исключительные ситуации.

## Инструмент
Диаграммы построены в PlantUML (https://plantuml.com), сгенерированы
в PNG. Исходный код — файлы `.puml`.
